## 🎯 QUICK ACTIONS

### Update Profile
1. Click button "Cập nhật hồ sơ"
2. Edit fields (name, phone, subjects, etc.)
3. Click "Lưu thay đổi"

### Accept/Reject Class
1. Go to Tab "Lớp học"
2. Find class with status "Chờ duyệt"
3. Click "Nhận" or "Từ chối"

### Mark Session
1. Go to Tab "Lịch dạy"
2. Find session with status "Sắp dạy"
3. Click "✓ Dạy" or "Nghỉ"

### View Details
1. Any tab with "Chi tiết" button
2. Dialog popup with full info
